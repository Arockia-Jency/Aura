🌌 Aura: Spatial Environmental Guardian
Transforming silence and sound into a living sensory experience.
Aura is a high-performance iOS application built in 2026 to visualize the invisible data of our surroundings. By combining real-time audio analysis with fluid, generative design, Aura creates a "digital twin" of your environment’s energy.

✨ Key Features
Living Orb Interface: A 3D-style glass entity that reacts, pulses, and scales based on real-time decibel input.

Dynamic MeshGradients: Sophisticated background shaders that shift colors (Calm, Energetic, Stressed) using organic grid manipulation.

Adaptive Haptic Textures: Driven by Core Haptics, the app provides tactile "heartbeats" that map directly to environmental noise intensity.

Morphing UX: High-fidelity transitions using @Namespace and matchedGeometryEffect to seamlessly expand the orb into a detailed analytics card.

Real-time Analytics: Historical noise tracking via Swift Charts with Catmull-Rom interpolation for smooth, mountain-like data visualizations.

Aura Share: Instant, high-resolution "Aura Postcards" generated via ImageRenderer for sharing environmental snapshots.

🛠 Tech Stack & Frameworks
Aura is built using the latest Swift 6 standards and a strict MVVM architecture:

SwiftUI: For the entire declarative UI layer.

Observation Framework: Using @Observable for high-performance, reactive state management.

AVFoundation: Low-latency microphone polling and AVAudioRecorder metering.

Core Haptics: Custom transient haptic patterns for physical feedback.

Swift Charts: Dynamic, time-based data visualization.

ImageRenderer: Server-side quality rendering for social sharing.

🔒 Privacy & Safety
Aura is designed with privacy at its core. It uses the microphone solely for Peak Power Metering.

No audio is recorded.

No data is stored or transmitted.

Analysis happens entirely on-device.

🎨 Design Philosophy
Aura follows Neu-Glassmorphic principles. Every element is designed to feel like a physical object made of light and frosted glass, utilizing blur effects and translucent materials to ensure the UI feels part of the user's physical space.
